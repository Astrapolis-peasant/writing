# Andrej Karpathy

Author of the LLM wiki pattern this vault implements ([[LLM Wiki (Karpathy)]]).

## Relevant positions

- Publishes ideas as deliberately abstract "idea files" meant to be handed to an
  agent and instantiated collaboratively, rather than as reference implementations.
  The stated goal is to communicate a pattern and let the agent work out specifics.
- Treats the schema file (`CLAUDE.md` / `AGENTS.md`) as the key configuration
  artifact — the thing that converts a general chatbot into a disciplined
  maintainer — and expects it to be co-evolved with the user over time.
- Prefers ingesting sources **one at a time**, staying in the loop to read
  summaries and steer emphasis, over unsupervised batch ingestion. Notes batching
  is viable but is an explicit tradeoff of supervision for throughput.
- Frames the tooling relationship as *"Obsidian is the IDE; the LLM is the
  programmer; the wiki is the codebase."*
